# 🛠️ ระบบรายงานการแจ้งซ่อมออนไลน์ PRTC (PRTC Repair Reporting System)
**วิทยาลัยเทคโนโลยีพระมหาไถ่ พัทยา**

ระบบบริหารจัดการและรายงานแจ้งซ่อมออนไลน์แบบ Single Page Application (SPA) ที่มีความคล่องตัวสูง รองรับการทำงานอย่างครบวงจรตั้งแต่การกรอกคำขอแจ้งซ่อม, การจ่ายมอบหมายงานของหัวหน้าฝ่ายอาคาร, การดำเนินงานบันทึกอะไหล่ของช่าง, ไปจนถึงการลงลายเซ็นดิจิทัลและตรวจรับงานโดยผู้สั่งแจ้ง พร้อมด้วยระบบคลังอะไหล่, แดชบอร์ดวิเคราะห์สถิติ, และการจำลองระบบแจ้งเตือนผ่าน LINE Notify

## 🌟 ฟีเจอร์เด่นของระบบ (Key Features)

### 1. 👥 ระบบสลับบทบาทผู้ใช้งาน (Demo Role Switcher)
- อยู่บริเวณมุมขวาบนของระบบ ช่วยให้ผู้สาธิตสามารถสลับบัญชีผู้ใช้เป็น **ครู/ผู้ส่งเรื่อง, หัวหน้างาน (Admin), หรือช่างซ่อมบำรุง** ได้ในทันทีโดยไม่ต้องจำรหัสผ่าน เพื่อทดสอบความต่อเนื่องของระบบ

### 2. 📝 ฝั่งผู้แจ้งซ่อม (ครู / บุคลากร / นักเรียน)
- **แบบฟอร์ม E-Form:** ดึงข้อมูลส่วนตัว (ชื่อ, ตำแหน่ง, แผนก) ของผู้ล็อกอินมาจัดกรอกให้อัตโนมัติ ป้องกันการกรอกข้อมูลผิดพลาด
- **รายการแจ้งซ่อมแบบหลายบรรทัด:** เพิ่มและลบแถวรายการชำรุดได้หลายรายการในใบเดียว
- **แนบภาพถ่าย:** รองรับการอัปโหลดไฟล์รูปภาพสิ่งของที่ชำรุดประกอบการพิจารณา
- **ตรวจรับงาน:** ประเมินดาวความพึงพอใจ (1-5 ดาว), เขียนรีวิวการแก้ไข, พร้อมวาดลายเซ็นดิจิทัลเพื่อยืนยันการรับงาน หรือเลือกส่งงานคืนช่างเพื่อแก้ไขกรณีที่ยังไม่เรียบร้อย

### 3. 👨💼 ฝั่งหัวหน้าฝ่ายอาคารสถานที่ (Head / Admin)
- **Dashboard สรุปภาพรวม:** การ์ดสถิติจำนวนเคสแต่ละสถานะ, คะแนนความพึงพอใจเฉลี่ย, ยอดสะสมค่าอะไหล่ และคำนวณระยะเวลาเฉลี่ยในการเข้าซ่อมและปิดงาน (SLA)
- **กราฟรายงานสถิติ:** แสดงตำแหน่งที่ชำรุดบ่อยที่สุด 5 ลำดับแรก (ดึงข้อมูลอัตโนมัติด้วย Chart.js)
- **ระบบจัดงาน:** เลือกระบุช่างรับผิดชอบ, กำหนดระดับความเร่งด่วน (ปกติ / ด่วนมาก 🔴), ลงลายเซ็นอนุมัติสั่งงาน
- **คลังอะไหล่ (Inventory Light):** เพิ่ม/แก้ไขรายการอะไหล่, ราคาประเมิน, ยอดขั้นต่ำเตือนภัย และระบายยอดสต็อกอัตโนมัติเมื่อช่างทำการเบิกใช้จริง

### 4. 🔧 ฝั่งช่างซ่อมบำรุง (Technician)
- **My Tasks:** แสดงตารางเฉพาะใบงานที่ตนเองได้รับมอบหมาย
- **ปุ่มรับงาน:** บันทึกเวลาเริ่มดำเนินการซ่อม
- **บันทึกรายงานซ่อม (Job Log):** บันทึกการแก้ไข, แสกนเบิกอะไหล่จริงจากคลังสินค้า, แนบรูปถ่ายหลังซ่อมแซม, พร้อมลงลายเซ็นรับรอง

### 5. 🖨️ ระบบสั่งพิมพ์เป็นทางการ (Export PDF / Print Template)
- มีปุ่ม "พิมพ์เอกสารใบรายงาน" ที่จัดโครงสร้างและสไตล์ให้มีรูปแบบใกล้เคียงกับ **ใบคำขอแจ้งซ่อมบนกระดาษแบบดั้งเดิม** โดยมีบล็อกการลงลายเซ็น 4 ส่วน และรูปถ่ายครบถ้วน สามารถสั่งพิมพ์หรือกด "บันทึกเป็น PDF" ผ่านเบราว์เซอร์ได้ทันที

### 6. 📱 ระบบแสกน QR Code ประจำจุด/ห้อง
- ระบบมีแผ่นพิมพ์ [qr_codes.html](file:///c:/Users/PC/Desktop/Programmer/PRTC%20Repair%20Reporting%20System/qr_codes.html) เพื่อให้ผู้ใช้สามารถคลิกบัตรพิกัด หรือเปิดแสกนเพื่อป้อนข้อมูลห้อง เช่น `ห้องคอม 101` หรือ `ห้องเรียน 302` ลงในฟอร์มแจ้งซ่อมได้ทันทีโดยไม่ต้องคีย์ข้อมูลเอง

### 7. 🔔 ระบบแจ้งเตือน LINE Notify (Simulated & Real API)
- ระบบจำลองการยิงข้อความ LINE แจ้งเตือนไปยังหัวหน้า (เมื่อมีงานเข้า) หรือไปยังผู้แจ้ง (เมื่อช่างซ่อมเสร็จ) ผ่านกล่อง **LINE Log (ปุ่มเขียวล่างขวา)**
- **ใช้งานจริง:** สามารถนำ Developer Token ของ LINE Notify มากรอกใส่ช่องตั้งค่าเพื่อทำการส่งข้อความแจ้งเตือนเข้าสู่แอปพลิเคชัน LINE ของจริงได้ทันที!

## 🎬 แนะนำโฟลว์การสาธิตการทำงาน (End-to-End Demo Workflow)

1. **ส่งคำแจ้งซ่อม (ครูผู้แจ้ง):**
   - สลับบทบาทมุมขวาบนเป็น `ครูสมศรี มีสุข` ➔ กรอกอาการชำรุด "เครื่องกรองน้ำรั่วซึม"
   - ในช่องสถานที่ ให้กดปุ่ม QR ด้านขวา หรือปุ่มจำลอง QR ซ้ายล่าง เพื่อสแกนห้องเป็น `สหกรณ์โรงเรียน`
   - แนบรูปถ่ายสิ่งชำรุด (ถ้ามี) ➔ กดส่งข้อมูลแจ้งซ่อม
2. **อนุมัติและสั่งช่าง (หัวหน้างาน):**
   - สลับบทบาทเป็น `หัวหน้าประสิทธิ์ รักงาน` ➔ ไปที่แท็บ **คำขอ & การจ่ายงาน**
   - จะเห็นใบงานของครูสมศรีขึ้นมา กดปุ่ม **จ่ายงานช่าง**
   - เลือกช่างรับผิดชอบเป็น `ช่างสมคิด ว่องไว`, กำหนดความเร่งด่วนเป็น `ด่วนมาก`, เขียนบันทึก, ลงลายเซ็นหัวหน้า ➔ กดตกลงอนุมัติ
3. **ดำเนินงานซ่อมและเบิกอะไหล่ (ช่างบำรุง):**
   - สลับบทบาทเป็น `ช่างสมคิด ว่องไว` ➔ ไปที่แท็บ **งานที่ได้รับมอบหมาย**
   - กดปุ่ม **เริ่มซ่อมงาน** ➔ สถานะใบงานจะเปลี่ยนเป็นกำลังดำเนินการซ่อม
   - ซ่อมเสร็จแล้ว กดปุ่ม **ลงบันทึกซ่อมเสร็จ**
   - ระบุผลการซ่อม "เปลี่ยนก๊อกน้ำชุดกรองน้ำใหม่"
   - เลือกเบิกอะไหล่จากคลัง: `ก๊อกน้ำอ่างล้างหน้า 1/2 นิ้ว` จำนวน `1` ชิ้น ➔ กดเพิ่มอะไหล่
   - อัปโหลดรูปภาพเสร็จสิ้น ลงลายเซ็นช่าง ➔ กดส่งรายงานซ่อมเสร็จ
4. **ตรวจรับปิดงาน (ครูผู้แจ้ง):**
   - สลับบทบาทเป็น `ครูสมศรี มีสุข` ➔ ไปที่แท็บ **ติดตามสถานะ & ประวัติ**
   - ใบงานจะเปลี่ยนสถานะเป็นสีส้ม "รอตรวจรับ"
   - กดปุ่ม **ตรวจรับและปิดงาน**
   - ให้คะแนนความพึงพอใจ 5 ดาว, เขียนคำติชม "ใช้งานได้ดีเหมือนเดิมค่ะ", พร้อมลงชื่อตรวจรับ ➔ กดปิดงาน
5. **วิเคราะห์ผล (หัวหน้างาน):**
   - สลับบทบาทเป็น `หัวหน้าประสิทธิ์` ➔ ไปที่แท็บ **แดชบอร์ดสรุปภาพรวม**
   - จะเห็นจำนวนเคสความสำเร็จ ยอดค่าใช้จ่ายอะไหล่สะสมที่เบิกไป และสถิติตำแหน่งการแจ้งซ่อมที่ได้รับการอัปเดตแบบเรียลไทม์
   - ไปที่แท็บ **คลังอะไหล่** ➔ ยอดคงเหลือของก๊อกน้ำจะถูกหักออกไป 1 ชิ้นโดยอัตโนมัติ
